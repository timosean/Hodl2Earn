# Hodl2Earn

CRA 없이 구성한 React, TypeScript, Webpack 스타터 프로젝트입니다. 컴포넌트 스타일은 SCSS 기반 CSS Module과 `classnames/bind`를 사용합니다.

## 요구사항

- Node.js
- Yarn Classic 1.x

## 설치

```bash
yarn install
```

## 개발 서버

```bash
yarn start
```

브라우저에서 `http://localhost:3000`으로 접속합니다.

## 타입 검사

```bash
yarn typecheck
```

## 프로덕션 빌드

```bash
yarn build
```

타입 검사와 프로덕션 빌드를 한 번에 실행하려면 다음 명령을 사용합니다.

```bash
yarn validate
```
