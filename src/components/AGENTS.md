# 공통 컴포넌트 지침

## 공개 API

- 가능한 컴포넌트는 해당 HTML 요소의 기본 속성과 외부 `className`을 지원한다.
- 공개 컴포넌트와 속성 타입은 `src/components/index.ts`에서 내보낸다.
- 컴포넌트 폴더에는 구현, 스타일, 테스트, 공개 내보내기 파일을 함께 둔다.

## 스타일과 토큰

- 컴포넌트 스타일은 `*.module.scss`와 `classnames/bind`를 사용한다.
- 색상, 간격, 모서리, 타이포그래피, 그림자, 제어 크기와 모션은 `src/styles/tokens.scss`의 CSS 변수를 사용한다.
- 터치 대상은 최소 44×44px, 버튼과 입력 높이는 최소 48px로 만든다.
- 비활성 상태와 로딩 상태에는 눌림 모션을 적용하지 않고 애니메이션 감소 설정을 존중한다.

## 접근성

- 의미에 맞는 HTML 요소를 우선 사용하고 키보드 조작과 `focus-visible` 표시를 유지한다.
- 아이콘만 있는 버튼에는 접근 가능한 이름을 필수로 제공한다.
- 설명, 오류, 로딩과 선택 상태를 적절한 ARIA 속성으로 보조 기술에 전달한다.
- 오버레이는 포커스 이동과 순환, 복원, ESC 닫기와 배경 스크롤 잠금을 지원한다.

## 테스트

- Vitest와 React Testing Library로 사용자에게 보이는 동작과 접근성 연결을 검증한다.
- 구현 세부 사항보다 역할, 이름, 상태와 사용자 상호작용을 검사한다.
- 각 동작은 실패하는 테스트를 먼저 확인한 뒤 최소 구현으로 통과시킨다.
