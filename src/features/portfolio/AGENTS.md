# 포트폴리오 기능 지침

## 책임

- 보유 항목의 티커, 통화, 평단가, 보유 수량을 등록·수정·삭제한다.
- 코인 이름은 입력받거나 저장하지 않는다.

## 데이터 규칙

- 티커는 공백을 제거한 뒤 대문자로 정규화한다.
- 통화는 `KRW`와 `USD`만 허용한다.
- `티커 + 통화` 조합을 고유 키로 사용하며 같은 조합의 중복 등록을 허용하지 않는다.
- 같은 티커라도 통화가 다른 `BTC/KRW`와 `BTC/USD`는 각각 등록할 수 있다.

## 저장소

- 초기 저장소는 `localStorage`를 사용한다.
- UI와 저장소 구현 사이에 저장소 인터페이스를 두어 향후 API로 교체할 수 있게 한다.
- 저장 데이터에 스키마 버전을 포함해 향후 마이그레이션을 지원한다.

## 표시 및 제외 범위

- 모바일 카드에 티커, 통화, 평단가, 보유 수량, 총 매수금액을 표시한다.
- 비중 차트와 환율 변환은 구현하지 않는다.
