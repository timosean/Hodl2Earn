# 평단가 계산기 기능 지침

## 입력

- 저장된 코인을 선택하고 가정 매수 단가를 직접 입력한다. 외부 시세 API는 사용하지 않는다.
- 투자 금액 입력을 우선하고 매수 수량 입력도 지원하며, 두 값은 자동 환산한다.
- 기존 항목과 시뮬레이션에는 같은 통화를 사용하고 환율을 변환하지 않는다.

## 정밀도와 수수료

- 수량은 소수점 이하 최대 8자리까지 지원한다.
- 수수료율 기본값은 `0.05%`이며 사용자가 수정할 수 있다.
- 투자 금액은 수수료를 포함한 총지출액이다.

## 계산

- `수수료 = 투자 금액 × 수수료율`
- `실제 매수 금액 = 투자 금액 × (1 - 수수료율)`
- `추가 수량 = 실제 매수 금액 ÷ 매수 단가`
- `변경 후 총수량 = 기존 수량 + 추가 수량`
- `변경 후 총투자금 = 기존 평단가 × 기존 수량 + 투자 금액`
- `변경 후 평단가 = 변경 후 총투자금 ÷ 변경 후 총수량`

## 결과

- 변경 후 평단가, 변경 후 총수량, 변경 후 총투자금을 표시한다.
- 평단가 증감액과 증감률, 수수료, 실제 매수 금액, 추가 수량을 표시한다.
- 결과는 실제 주문이나 투자 권유가 아닌 시뮬레이션으로 표현한다.
