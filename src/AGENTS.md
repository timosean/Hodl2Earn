# 프런트엔드 소스 지침

## UI

- 모바일 전용 단일 열 화면으로 만든다.
- 넓은 화면에서도 콘텐츠의 모바일 너비를 유지한다.

## 코드 구조

- TypeScript 엄격 모드를 유지하고 명시적인 도메인 타입을 사용한다.
- UI, 도메인 계산, 영속성 로직을 서로 분리한다.

## 스타일

- 컴포넌트 스타일은 `*.module.scss`와 `classnames/bind`를 사용한다.
- 전역 스타일은 최소화한다.

## 정밀도와 문구

- 금액과 수량에는 명시적인 정밀도 정책을 적용해 부동소수점 오차를 방지한다.
- 사용자에게 보이는 문구와 오류 메시지는 한글로 작성한다.
