# Hodl2Earn 에이전트 지침 설계

## 목표

프로젝트가 커져도 작업 위치에 필요한 규칙만 적용되도록 `AGENTS.md`를 계층형으로 구성한다. 공통 정책은 상위 파일에 두고 포트폴리오와 평단가 계산기 규칙은 각 기능 디렉터리에서만 관리한다.

## 파일 구조와 상속

```text
.
├── AGENTS.md
└── src/
    ├── AGENTS.md
    └── features/
        ├── portfolio/AGENTS.md
        └── calculator/AGENTS.md
```

하위 경로는 상위 지침을 상속하며 더 구체적인 하위 규칙을 우선한다. 하위 파일은 상위 내용이나 다른 기능의 규칙을 반복하지 않는다. 현재 앱 코드는 이동하지 않고 기능 지침 디렉터리만 만든다.

## 루트 지침

- 코인 보유 현황과 추가 매수 후 평단가를 계산하는 웹이라는 목적을 설명한다.
- TypeScript, React, Yarn Classic, Webpack, SCSS CSS Module을 공통 기술로 지정한다.
- `/Users/seungwoo/Projects/Hodl2Earn`에서 별도 worktree 없이 작업한다.
- 병합은 rebase 기반 선형 기록을 기본으로 한다.
- 모든 Markdown 문서는 한글로 작성한다.
- `yarn install`, `yarn start`, `yarn typecheck`, `yarn build`, `yarn validate` 명령과 완료 전 검증을 명시한다.

## 소스 공통 지침

- 모바일 전용 단일 열 UI만 만들고 넓은 화면에서도 모바일 너비를 유지한다.
- TypeScript 엄격 모드와 명시적인 도메인 타입을 유지한다.
- 컴포넌트 스타일은 `*.module.scss`와 `classnames/bind`를 사용한다.
- UI, 도메인 계산, 영속성 로직을 분리한다.
- 금액과 수량은 명시적인 정밀도 정책으로 부동소수점 오차를 방지한다.
- 사용자 문구와 오류 메시지는 한글로 작성한다.

## 포트폴리오 지침

- 티커, 통화, 평단가, 보유 수량을 등록·수정·삭제한다.
- 티커는 공백 제거 후 대문자로 정규화하며 코인 이름은 받지 않는다.
- 통화는 `KRW`와 `USD`만 허용한다.
- `티커 + 통화`를 고유 키로 사용한다. 같은 조합은 중복할 수 없지만 `BTC/KRW`와 `BTC/USD`는 각각 등록할 수 있다.
- 초기 저장소는 `localStorage`이며 UI와 저장소 구현을 인터페이스로 분리한다.
- 저장 데이터에 스키마 버전을 두어 향후 API와 마이그레이션을 지원한다.
- 모바일 카드에 티커, 통화, 평단가, 보유 수량, 총 매수금액을 표시한다.
- 비중 차트와 환율 변환은 제외한다.

## 계산기 지침

- 저장된 코인을 선택하고 사용자가 가정 매수 단가를 직접 입력한다. 외부 시세 API는 사용하지 않는다.
- 투자 금액 입력을 우선하고 매수 수량 입력도 지원하며 두 값은 자동 환산한다.
- 수량은 소수점 이하 최대 8자리를 지원한다.
- 수수료율 기본값은 `0.05%`이며 수정할 수 있다.
- 투자 금액은 수수료 포함 총지출액이다.
- `수수료 = 투자 금액 × 수수료율`
- `실제 매수 금액 = 투자 금액 × (1 - 수수료율)`
- `추가 수량 = 실제 매수 금액 ÷ 매수 단가`
- `변경 후 총수량 = 기존 수량 + 추가 수량`
- `변경 후 총투자금 = 기존 평단가 × 기존 수량 + 투자 금액`
- `변경 후 평단가 = 변경 후 총투자금 ÷ 변경 후 총수량`
- 결과에는 변경 후 평단가·총수량·총투자금, 평단가 증감액·증감률, 수수료, 실제 매수 금액, 추가 수량을 표시한다.
- 기존 항목과 시뮬레이션은 같은 통화를 사용하며 환율을 변환하지 않는다.
- 결과는 실제 주문이나 투자 권유가 아닌 시뮬레이션이다.

## 검증 기준

- 네 `AGENTS.md`는 모두 한글로 작성한다.
- 계산 공식은 계산기 지침에만, 저장과 중복 규칙은 포트폴리오 지침에만 둔다.
- 작성 후 `git diff --check`와 `yarn validate`를 실행한다.
